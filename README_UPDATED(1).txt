AI Student Performance System - Updated

Features:
1. Register with Name, Email, Phone and Password.
2. Login using Email OR Phone + Password.
3. Page 1: Year, Semester, Branch, Attendance, 5 Subject Marks,
   5 Assignment Marks, 5 Internal Marks and Study Hours.
4. Page 2: Performance prediction.
5. Page 3: Prediction history.
6. SQLite database is created automatically.

Run:
cd /d "%USERPROFILE%\Desktop\AI_Student_Performance_System"
py -m pip install -r requirements.txt
py app.py

Open:
http://127.0.0.1:5000
